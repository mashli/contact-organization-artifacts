# Robotica — frozen predictive / qualification readout

Companion package for the *Robotica* manuscript:

> Auditing Contact Organization in Contact-Rich Manipulation:
> Qualification Criteria, Selective Failures, and a Null Predictive Result

Public mirror: https://github.com/mashli/contact-organization-artifacts
(path: `results/robotica/`, `configs/robotica/`, `scripts/robotica/`).

> **Overlap disclosure.** Simulation tooling overlaps with a separate RAS
> manuscript by the same author (ROBOT-D-26-01372R1, force–mass abstraction).
> Claims, experiments, and data for Contact Organization / Scheme D / OPCG /
> $\mathfrak{S}_0$ are specific to this Robotica package and are not reused
> there. This repository previously hosted IJRR Paper I/II artifact stubs;
> the Robotica paths above are the current source of truth for the numbers
> cited in the Robotica submission.

> **Label note.** The `qualification_status` / `role` columns in the predictive
> CSVs are the **preregistered cohort roles** from
> `configs/existing_trajectory_map.yaml` (hash-locked before scoring).
> They are not signature verdicts. In particular, ellipsoid carries the
> preregistered role `qualified_positive_transfer`, while the later signature
> round (`sig_witness_round.csv`) returns P1 fail and `Sig = ⊥` for ellipsoid.
> The manuscript uses the signature verdict. Labels were not edited, so the
> preregistration hashes below stay valid.
>
> MSM diagnostics (`*_msm_diagnostics.json`, `msm_diagnostics_summary.json`)
> are the source of the block λ2 = 0.889 [0.877, 0.899] and cylinder
> λ2 = 0.847 numbers.

Generated by `scripts/run_predictive_readout.py`. Existing trajectories only.
No geometry was dropped after scoring.

## Split

- unit: episode
- fractions: train 0.6, val 0.2, test 0.2
- seed: 0
- stratification: episode-level escape label, with a shuffle fallback if a class has <3 episodes
- leakage control: asserted empty intersection of train/val/test episode IDs
- fit_on_train_only: KMeans, HMM EM, scalers, and logistic readouts
- fx_threshold: 8.0 (frozen; not tuned on val or test)
- next_horizon: 1

## Predictive headline (null vs B0n)

Primary scientific reading for the Robotica rewrite: relative to
`scalar_fx_quadratic` = $[\mathrm{f}_x,(\mathrm{f}_x-t^\ast)^2]$ (B0n),
organization shows **no stable held-out advantage** on the audited tasks.
Force-blind clustering is a negative control only. Escape AUCs are
secondary (few positive episodes).

See manuscript Section 6 and `predictive_paired_delta_ci.csv`.
